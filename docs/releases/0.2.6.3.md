# Codex Agent Switch 0.2.6.3

0.2.6.3 restores and hardens the existing Context Economy path without adding
another compaction system or any model calls.

## Root cause

`model_context_window:null` reached unsafe numeric parsing, raised an
`InvalidOperationException`, aborted the usage scan, failed the Main context
boundary, and was then hidden by the Stop Hook's fail-open catch. Context
Economy therefore never received usable telemetry or bound the affected Main
thread.

## Fix evidence

- Numeric usage fields now accept only JSON numbers; null, missing, and other
  JSON kinds are treated as unavailable. Event and file failures are isolated,
  with sanitized local diagnostics and scan metrics.
- The repository's 63 historical null context-window events scan without an
  exception. A current-host scan covered 67 files with 0 skipped events, 0
  failed files, and 68 produced records in 1.626 seconds.
- Parser and usage isolation tests: 16/16 passed. Scheduler boundary tests:
  6/6 passed. Stop Hook process/pipe tests: 2/2 passed.
- Direct ToolHost to named-pipe Scheduler coverage proves binding, persisted
  `main_context_economy` state, business-reason handling for missing sessions,
  and project-scoped terminal-result gating.
- The Stop Hook remains fail-open but now records deterministic, sanitized JSONL
  evidence for success and failure without prompt or raw input content.
- Live acceptance used disposable workspace
  `E:\AISPace\CAS-test-root-0263\context-economy-live-d92f594fe5db4bf3b58e37f787570630`.
  Native `contextCompaction` started and completed events were observed for
  thread `01a016f0-9d2e-7c70-963f-4e0cf17f8297`. Pre-compaction input median
  was 136,745 tokens; the two post-compaction samples were 19,676 and 19,698,
  producing a 19,687 median and an 85.6% reduction. SQLite classified the
  result Effective.
- Full regression: Core 330/330, Bootstrapper 19/19. Release solution build:
  0 warnings and 0 errors.

## Scope evidence

- No new LLM call, summarizer, reviewer, watcher, database, scheduler, or
  compaction implementation was added. Compact still uses Codex App Server's
