# Codex Agent Switch 0.2.4.2

## OpenCode Zen API mode

- OpenCode Zen now uses the direct `https://opencode.ai/zen/v1` Chat Completions API.
- The official `GET /models` catalog remains the availability source, intersected with the explicit supported model allowlist.
- This release exposes only models documented for `POST /chat/completions`; Zen `/responses`, `/messages`, and Gemini native endpoints remain hidden until Agent Switch has matching tool-call transports.
- Zen API keys are stored only through `ICredentialStore` at `provider/opencode-zen`; configuration and logs persist only the reference and selected model.
- Connection testing sends one short Chat Completions request and enables the provider only after success.
- Zen workers use the existing `OpenAiCompatibleWorkerAdapter` and external-agent runtime. OpenCode CLI/PATH/login checks are no longer on the normal path.

DeepSeek and generic OpenAI-compatible providers retain their existing transports and behavior.
