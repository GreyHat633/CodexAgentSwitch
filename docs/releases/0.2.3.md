# Codex Agent Switch 0.2.3

0.2.3 changes managed delegation from a one-time routing decision into proactive,
continuous ownership re-evaluation. Main localizes and decides architecture, bounded
implementation can move to the configured Worker, and every meaningful phase change
can produce a new auditable MAIN/WORKER decision.

## Highlights

- Added an Initial Delegation Check after minimum read-only localization.
- Added all eight distinct Repartition triggers without merging their semantics.
- Added deterministic current-package evaluation over seven positive delegation
  conditions; a LOW/MEDIUM package prefers Worker at four or more positive signals.
- Added closed MAIN and WORKER reason-code sets with owner/reason validation.
- Added lightweight current-work and repartition record models.
- Added append-only SQLite repartition telemetry, Scheduler IPC methods, and strict
  `record_repartition` / `list_repartitions` MCP tools.
- Kept the default active Worker limit at one while explicitly permitting later
  serial Worker packages after a terminal result and bounded review.
- Preserved anti-duplication, `fork_turns="none"`, existing native/external transports,
  provider endpoints, and credentials.
