# Codex Agent Switch 0.2.6.1

0.2.6.1 is a focused stability patch over 0.2.6.

- Pending repartition and Hard Gate state now survives Scheduler/ToolHost restart.
- Scheduler monetary usage records use existing verified usage and pricing data;
  unknown cost remains unknown and cannot silently pass configured daily or
  monthly limits as zero.
- Background exec-continuation correlation is written to
  `logs/continuation-correlation.jsonl` without adding Main turns, tools,
  polling, retries, or prompt content.

Native Luna routing, Context Economy, External Worker lease limits, AGENTS
generation, and package-completion behavior are unchanged.
