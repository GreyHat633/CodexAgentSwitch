# Codex Agent Switch 0.2.4.1

0.2.4.1 是一个有界运行时集成修复：把 0.2.4 已有的 `SessionContextBudget`、原生 Thread compact 与 rollover/checkpoint 能力接入真实 Main Session 生命周期。

## 修复

- 每个已有 Main Thread 在开始后续 Main 工作前评估 `SessionContextBudget`。
- `Compact` 实际调用 `CompactThreadAsync()`，并避免同一 Thread 在达到 rollover 前重复 compact。
- `Rollover` 生成现有 `CompactCheckpoint`，调用 `RolloverThreadAsync()` 回放 checkpoint，持久化新 Thread ID，并让当前待处理工作及后续 Main 工作只在新 Thread 继续。
- 保留 0.2.4 的默认年龄、turn 与 normalized-credit 阈值；未修改 Context Economy 设计。

## 有界验证

- 无真实模型的 `ControlledTaskService` 生产链集成测试覆盖 Continue、Compact 与 Rollover。
- 未运行自然模型验收、40/60 credits 实测、完整 Release Gate、部署、C 盘审计或 UI 验收。
