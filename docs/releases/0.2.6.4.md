# Codex Agent Switch 0.2.6.4

0.2.6.4 restores the real Codex command-hook contract and replaces the broad
ownership gate with a deterministic exact-path fuse.

## Production hook contract

- Managed command hooks now contain the required non-empty `command` field and
  retain `commandWindows` as the Windows override.
- Reconcile migrates legacy CAS `commandWindows`-only entries, preserves
  unrelated hooks, remains idempotent, and refuses to overwrite malformed JSON.
- The independent validator parses hook JSON and verifies the ToolHost hook and
  pipe arguments rather than searching for CAS strings.
- `PreToolUse`, `PostToolUse`, and `Stop` are generated. `PostToolUse` is the
  only source of successful Worker touched paths.

## Conservative Hard Gate v2

- Production defaults to Shadow mode.
- Evaluation requires exact `main_turn` actor identity, one RUNNING native
  Worker in the same session and cwd, a structured `Edit`, `Write`, or
  `apply_patch` target, and an exact match with a successful Worker
  `PostToolUse` touched path.
- Generic shell, unknown actors, unresolved paths, ambiguous workers, other
  sessions, terminal Workers, missing telemetry, and infrastructure failures
  all allow execution.
- Shadow records `WOULD_DENY` without denying. Enforcement remains disabled
  until real Codex Desktop Shadow acceptance is complete.

## Observability

- Runtime diagnostics expose Pre/Post/Stop counts and timestamps, Context
  Economy boundary/binding/pressure/compaction fields, aggregate Hard Gate
  counters, and the last exact Hard Gate boolean event.
- Diagnostics are zero-model-cost and do not add agent turns or delegation.

## Acceptance boundary

Internal contract, integration, regression, and Release build results are not
equivalent to Codex Desktop production acceptance. Hook UI loading, real
Pre/Post/Stop delivery, Shadow behavior, and Context Economy state binding must
still be verified in a trusted real project before enforcement or release GO.
