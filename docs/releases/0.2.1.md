# Codex Agent Switch 0.2.1

0.2.1 completes the integrated Worker-effort, launch, Provider feedback, native-usage, and Economic Policy v2 work while keeping the previously verified transport boundary unchanged.

## Highlights

- Worker reasoning effort is independently selectable, persisted, migrated, displayed, and applied to native Worker launches.
- Dashboard uses one global `启动 Codex` action with project selection and visible start/success/failure states.
- Ambiguous per-project reconfiguration and launch actions were removed from project cards.
- `测试当前 Worker` has guarded Testing/Success/Failed states and cannot create duplicate concurrent tests.
- Provider card actions now show their result outside the collapsed editor.
- Activity and recent results remain Scheduler/persistent-history backed.
- Native Codex JSONL usage is read-only and separated into Sol, Luna/native Worker, cached, uncached, output, and reasoning values.
- External Provider tokens/costs and Native Codex tokens remain separate in the UI.
- Economic Policy v2 expresses LOW/MEDIUM/HIGH risk, review budgets, compact results, escalation checkpoints, and a default active Worker limit of one.
- Usage opens at the top after asynchronous projection updates instead of retaining an unexpected middle-page offset.

## Compatibility and safety

- No NativeWorkerExecutor, ExternalWorkerExecutor, provider transport, ToolHost transport, adapter transport, or `fork_turns` protocol refactor was made.
- Existing 0.2.0 project/profile/provider data migrates forward; profile schema version is 3.
- Display acceptance used the host's actual 125% DPI setting. Windows scaling was not changed.
- Provider click-through used an isolated credential namespace and did not call DeepSeek.

## Verification

- Debug and Release builds passed with zero warnings/errors.
- 147/147 automated tests passed.
- Global Codex launch activated the installed Codex Desktop application using an isolated applied project.
- Profile, Provider, pause/resume, Activity, project configuration, and key navigation controls passed click-through.

See `docs/acceptance/0.2.1/acceptance-report.md` for the complete evidence matrix and economic acceptance notes.
