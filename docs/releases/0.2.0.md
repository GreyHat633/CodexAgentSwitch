# Codex Agent Switch 0.2.0

0.2.0 是一次面向日常使用的 UI、状态展示与交互重构，同时保留 0.1.13 已验证的 Sol、Luna、DeepSeek 与项目配置链路。

## 主要变化

- 首页改为 Agent Switch 运行总览，集中展示项目、已应用方案和活动任务。
- 项目配置与启动 Codex 分离，配置页只负责将方案应用到项目。
- 新增活动任务页，展示 Worker 类型、模型、状态、耗时和最近结果。
- 用量与预算、服务商、配置方案页面统一使用真实状态投影，并明确不可取得的数据。
- 修复方案页空状态灰色竖条，补充响应式布局和系统托盘暂停、退出说明。
- 版本元数据统一更新为 0.2.0。

## 验收证据

- Windows 125% DPI 长期实际使用环境下完成规定状态截图和 1366 有效布局矩阵。
- 页面无文字截断、控件溢出、异常空白或不可操作主按钮。
- Release/Debug x64 构建均为 0 警告、0 错误。
- `CodexAgentSwitch.Tests`：117/117 通过。
- `CodexAgentSwitch.Bootstrapper.Tests`：19/19 通过。
- Portable、安装后应用和 Runtime Bootstrapper 均已真实启动。
- C 盘物理写入审计通过。
- UI 验收期间真实 Luna、DeepSeek/API 调用均为 0。
