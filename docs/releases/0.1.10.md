# Codex Agent Switch 0.1.10

本版本只修复 0.1.9 的原生 Codex 项目适配和旧 Profile 兼容问题；不会改变已正常工作的 CodexAgentSwitch 内置 DeepSeek 执行链。

- 原生项目配置现在只写入经过当前 Codex 严格加载验证的白名单字段：主模型、推理强度、批准策略、沙箱策略和原生子代理默认项。Provider、预算、Profile 元数据、项目绑定、`model_provider` 与 `model_providers` 一律不会写入 `<项目>\.codex\config.toml`。
- 写入先生成同目录临时文件，再由当前 Codex 执行严格 TOML/配置加载校验；校验成功后才备份并原子替换。失败时原 `config.toml` 保持不变。
- 原生 Codex 模式不再把名为 DeepSeek 的 Terra 子代理当作真实外部 Provider 调用。当前版本明确仅支持 Sol、Terra、Luna 原生 Worker；DeepSeek 继续只在 CodexAgentSwitch 模式中使用真实 ExternalWorkerAdapter。
- 旧版 Profile 增加 schema v2 幂等迁移；历史“经济模式”会补齐当前合法字段。无法解析的旧数据会显示“需要修复”的中文提示，不会导致编辑页或应用退出。用户删除旧经济预设后不会在下次启动时自动复活。

Windows 10 22H2 x64 是主验收环境；Windows 11 保持兼容。升级不会覆盖现有 Profile、Provider 或凭据。
