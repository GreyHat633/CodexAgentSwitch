# Codex Agent Switch 0.2.2

0.2.2 upgrades OpenAI-compatible external providers from text-only workers to coding workers that can request local tools, observe results, continue across turns, validate work, and self-repair.

## Highlights

- Added a provider-neutral external agent runtime with bounded multi-turn tool calling.
- Added real PowerShell `shell` execution and scoped `apply_patch` support, including unified diff and Codex `*** Begin Patch` formats.
- Added Read Only, Workspace Full Access, and Full Access execution modes independently from approval automation.
- Added capability declarations and pre-spawn routing checks for project read, search, patch, shell, build/test, multi-turn, and self-repair.
- Added compact worker results with changed files, validation, risks, provider turns, tool calls, duration, tokens, and activity records.
- Added an external-worker permission selector to the Profile editor without changing the existing provider HTTP endpoint or credential transport.
- Added termination guards for cancellation, wall-clock timeout, repeated identical calls, maximum provider turns, and maximum tool calls.

## Verification

- Real DeepSeek `deepseek-v4-flash` A-G ladder passed: text, read-only shell, file creation, patch/build/test/self-repair, workspace denial, and harmless Full Access read.

- Debug and Release validation: 183/183 automated tests passed; x64 app build completed with zero warnings and zero errors.
- Dark-theme Profile UI smoke: 10/10 actions passed at reported DPI 119; the independent external permission selector was visually inspected.
- C-drive release audit passed for portable, installed, and runtime-bootstrapper entry points with no monitored physical C-drive changes.
