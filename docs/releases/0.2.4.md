# Codex Agent Switch 0.2.4

0.2.4 完成了主动分工硬化、Main 成本窗口、上下文经济性和 OpenCode Zen 配置闭环。当前源码、自动化回归、Release x64 构建、发布包、E 盘部署及中文 UI 验收均已完成；但原计划限定的唯一一次自然主动分工验收没有成功创建 Worker Job，因此本版本不能标记为总体 PASS，需在另行授权一次自然重测后关闭该验收项。

## 主要变化

- 新增按 Session 与项目目录隔离的 Main Cost Guard，按合成 Usage 增量执行 `25 → 40 → 60 → 60` normalized credits 阈值；Cached Input、Uncached Input、Output 分别计权，Reasoning 仅报告、不重复计费。
- 新增持久化 Work Package Lease、Ownership Gate、保守型 Mutation Classifier、PreToolUse Hook 和 ToolHost IPC；未决写入、Worker 所有权下的 Main 重复写入会被拒绝。
- Worker 结束、审查完成、新包、成本检查点等边界会使旧 Lease 失效并要求新的 Repartition Decision；active worker=1 仍只是并发上限。
- 新增 Compact Checkpoint、Session Context Budget、真实 `thread/compact` 与新 Thread rollover/replay 调用；不伪造 token 级实时中断。
- 统一 Provider Registry，使 OpenCode Zen 从 Onboarding、Providers、Profiles、持久化选择到运行时路由使用同一数据源；动态模型刷新失败时保留已保存的 raw model ID，Zen 不读取或保存第二份 API Key。
- 诊断页增加经济/所有权运行状态；本版本新增的用户可见状态、帮助、错误和按钮文本已中文化。协议标识、模型/Provider 名、命令、PATH、raw model ID 及外部原始输出保持不翻译。
- 修复自然验收发现的嵌套 cwd 解析问题：未显式提供 ProjectId 时，选择包含任务目录的最具体已注册项目；相似目录名前缀不会被误认成子目录。
