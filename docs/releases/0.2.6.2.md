# Codex Agent Switch 0.2.6.2

0.2.6.2 is a bounded External Worker stability and archived-project runtime
guard release over 0.2.6.1.

- External scheduler dispatch now returns after durable delegation while the
  Worker runs independently. Terminal results persist as `ResultPending` and
  are delivered exactly once at a natural Main boundary.
- Blocked and failed External outcomes have a legal review path and expose one
  compact decision packet with scope, changed files, validation state,
  terminal reason, and bounded recovery/retry facts.
- The lifetime identical-call counter is replaced by a recent no-progress
  guard with canonical call keys, bounded evidence, one generic in-context
  recovery instruction, triggering-call preservation, and a stable terminal
  reason.
- A narrow mechanical allowlist permits at most one fresh External retry while
  preserving the original task scope and current workspace.
- Archived projects are excluded at the runtime resolution boundary for direct
  paths, explicit project IDs, and Git worktree adaptation; unarchive restores
  eligibility without rewriting the saved adaptation.

This release does not add polling or semantic recovery calls to Main, does not
automatically transfer a failed Worker package to Main, and does not change
Native Luna routing, waiting, limits, retry behavior, or telemetry.
