# Codex Agent Switch 0.1.8

- CodexAgentSwitch 模式的消息列表改为稳定集合与原位流式更新；自动跟随滚动经过节流，用户上滚时显示“回到底部”。
- 原生 Codex 模式默认启动检测到的官方图形桌面应用（Windows AppUserModelId 或手动图形入口），不再把 CLI/TUI 作为静默回退；CLI 保留为显式高级入口。
- 首次启动向导实现环境、主代理、工作代理、服务商、确认五个真实步骤，完成后创建并启用 Profile；已有用户方案会保留且不会被向导打断。
- 统一首次向导、配置方案、设置和受控对话的页面边距、最大内容宽度与响应式断点；项目和对话操作收敛到“更多”菜单。

Windows 10 22H2 x64 是主验收环境；Windows 11 继续兼容。此版本不写入或覆盖用户已有的全局 Codex 配置、Profile 或凭据。
