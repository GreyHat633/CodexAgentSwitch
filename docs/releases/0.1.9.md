# Codex Agent Switch 0.1.9

- 原生 Codex 模式改为正式的多项目适配流程：添加或新建项目、搜索、多选、明确确认、逐项结果、备份和恢复都在独立响应式页面完成。
- 只会修改用户明确勾选的 `<项目>\.codex\config.toml` 管理块；无关配置保留，原始内容可恢复。完成适配后启动检测到的官方 Codex 桌面应用，不再自动使用隐藏工作目录。
- CodexAgentSwitch 模式新增项目默认方案、对话创建快照，以及从下一轮应用当前方案到单个对话或项目全部对话的显式入口；已有 Turn 不会被静默改写。
- 修复 0.1.8 便携包在 Windows 10 22H2 上使用 WinUI 自包含运行时时的 XAML 初始化崩溃。0.1.9 主便携包采用稳定的多文件框架依赖部署，发布包同时包含可离线检查/安装 Windows App Runtime 的 Bootstrapper；主 App 需要 .NET 8 x64 Desktop Runtime。

Windows 10 22H2 x64 是主验收环境；Windows 11 保持兼容。升级不会覆盖用户已有的 Profile、Provider 或凭据。
