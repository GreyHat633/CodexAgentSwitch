# UI Wireframes

## 信息架构

```text
Codex Agent Switch
├─ 首页
├─ 配置方案
├─ Provider
├─ 运行任务
├─ 用量与预算
├─ 历史记录
├─ 设置
├─ 诊断
├─ 首次启动向导
└─ UI Gallery
```

## 首页

```text
┌──────────────────────────────────────────────────────────┐
│ 早上好                         [应用并重启] [启动 Codex] │
├──────────────────────────────────────────────────────────┤
│ 当前 Profile：经济模式 · Sol high + Luna                 │
├──────────────────┬──────────────────┬────────────────────┤
│ 主代理           │ Worker 策略      │ 预算               │
│ Sol high         │ Luna ×1          │ ¥0 / ¥3            │
├───────────────────────────────┬──────────────────────────┤
│ 最近任务：采用/重复/经济判断  │ 环境状态                 │
└───────────────────────────────┴──────────────────────────┘
```

## 运行任务

```text
主代理 Sol
├─ plannedSkippedWork / duplicateWork
├─ Worker 1：运行中 / 继续等待 / 纠偏 / 取消
└─ Worker 2：等待批准 / 查看请求 / 拒绝并纠偏
```

## 首次向导

```text
环境检测 → 主代理卡片 → Worker 来源 → 可选 Provider → 人类可读确认
```

## 渐进披露

- 首页不展示原始 JSON、Thread ID 或大段日志。
- Provider 仅在展开配置时显示 Base URL、Key 与 Model ID。
- 设置页高级协议参数默认折叠。
- 诊断页保留脱敏原始详情和恢复操作。
