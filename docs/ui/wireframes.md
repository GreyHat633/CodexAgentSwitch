# UI Wireframes

## 信息架构

```text
Codex Agent Switch
├─ 首页（双模式入口与真实 Profile 状态）
├─ 配置方案（含批准操作模式）
├─ 服务商
├─ CodexAgentSwitch 模式
│  ├─ 项目
│  └─ 对话（受控主 Thread）
├─ 用量与预算
├─ 历史记录
├─ 设置
├─ 诊断
├─ 首次启动向导
└─ 界面预览
```

## 首页

```text
┌────────────────────────────────────────────────────────────┐
│ 当前方案 · 主代理 · Worker · 批准模式                         │
├───────────────────────────┬────────────────────────────────┤
│ 原生 Codex 模式             │ CodexAgentSwitch 模式          │
│ 配置并启动原版 Codex         │ 项目、对话、Worker、Usage、归档 │
│ 只管理启动配置               │ 受控 Thread 的真实状态          │
└───────────────────────────┴────────────────────────────────┘
```

Worker 卡片完全由当前 Profile 绑定：外部 Provider 显示 Provider 与模型；原生 Worker 显示实际选中的角色；禁用时显示“未启用”；Provider 不可用时显示“配置异常”。首页不出现模拟任务、硬编码 Luna 或“可能节省”等演示数据。

## CodexAgentSwitch 模式

```text
┌──── 项目 / 对话（280px，<1100px 自动收起） ────┬── 对话主区域 ──┐
│ 项目 + 新建                                      │ 标题 / 方案 / Thread │
│ 项目列表（上限高度）                             │ 可虚拟化消息列表      │
│ 项目操作                                         │ 用户 / 主代理消息     │
│ 对话 + 新建                                      │ 代码、Diff、工具、    │
│ 对话列表（填充余量）                             │ Worker、Usage 可折叠  │
│ 对话操作                                         ├───────────────────┤
│                                                   │ 固定多行输入与发送   │
└───────────────────────────────────────────────────┴───────────────────┘
```

在较窄窗口，左栏自动收起为“显示侧栏”按钮，避免项目和对话占用阅读宽度；用户也可手动显示或隐藏。输入区固定在对话底部，阅读历史时自动滚动不会强行拉回底部。

## 批准操作模式

```text
配置方案
├─ 安全模式：任何非可信命令或越界写入需批准；只读沙箱
├─ 自动模式：工作区内读写自动进行；风险操作请求批准
└─ 完全自动：不请求批准；危险级本地访问（明确警告）
```

所有页面都使用 Windows 10 可用的纯色浅色/深色资源和系统字体回退；不依赖 Mica、系统材质、Windows 11 专属标题栏或 Snap Layout。
