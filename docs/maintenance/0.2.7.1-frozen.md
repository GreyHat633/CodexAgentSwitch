# CodexAgentSwitch v0.2.7.1 Freeze Record

v0.2.7.1 was an internal, unreleased active-compaction experiment. Its Desktop thread-control approach did not pass production acceptance and is frozen. It must not be used as a production baseline.

v0.2.7.2 is rebuilt from the released v0.2.7.0 baseline. It does not carry forward the v0.2.7.1 Stop Hook or active Desktop thread-control experiment.

Instead, v0.2.7.2 deploys a project-level native Codex auto-compaction threshold to selected CAS-managed projects. Codex Desktop remains responsible for detecting the threshold and performing native automatic compaction.
