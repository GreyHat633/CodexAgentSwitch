# 0.2.6.1 exec continuation correlation

`logs/continuation-correlation.jsonl` is a background diagnostic stream. It is
not appended to Main prompts or task messages and does not create model turns,
tool calls, polling, retries, or execution changes.

The shared correlation ID covers only boundaries visible to Codex Agent Switch:

- `WorkerResultInjected`
- `MainContinuationStarted`
- `ExecRequestObserved` (`commandExecution` item started)
- `ExecOutputObserved` (`commandExecution` item completed)
- `MainResumeObserved` (the first later Main event)

Codex Agent Switch cannot observe the App Server's internal command dispatch or
process transport. The log therefore does not claim an `ExecDispatchObserved`
stage. If a stall recurs, the last recorded observable boundary identifies where
the next investigation should begin; 0.2.6.1 intentionally adds no retry logic.
